# Security policy

Do not report a suspected vulnerability in a public issue.

Email [hi@pulsecommit.app](mailto:hi@pulsecommit.app?subject=Pulse%20Commit%20security%20report)
with the subject “Pulse Commit security report”. Include the Pulse Commit
version and build, iOS version, affected feature, potential impact, and safe
steps to reproduce.

Do not include Health exports, GitHub or Telegram tokens, Telegram chat IDs, or
personal health metrics. Redact names, repository details, message contents,
and other identifying information. If more evidence is needed, we will agree on
a safer way to provide it.

Security reports are reviewed on a best-effort basis. No acknowledgement or
resolution time is guaranteed.
